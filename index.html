Selected Work

Stockometer

Data visualization and interface design

alvinjoby.in/stockometer

A stock analysis platform where the design problem was showing a lot of market data without overwhelming the reader. I shaped the page and its charts so that price, RSI, MACD and moving averages read together at a glance, with a clear visual hierarchy and consistent chart styling. An index comparison view sets any stock against its market benchmark.

Design focus
Chart design, information hierarchy, visual comparison
Tools
Plotly, HTML, CSS, JavaScript

NIFTY Bank: Pre, During and Post COVID

Data storytelling and visual analysis

github.com/AlvinJoby/bank-nifty-covid

A visual study of how the NIFTY Bank Index behaved across three phases of the pandemic. The aim was to tell the story clearly: each phase is set up on the same terms, and the charts are shaped so the sharp decline and the recovery that followed are easy to see without reading the numbers.

Design focus
Visual comparison, narrative structure, clarity
Tools
Matplotlib, Jupyter Notebook
