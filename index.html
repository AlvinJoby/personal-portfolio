Selected Work

Stockometer

Data visualization and interface design

alvinjoby.in/stockometer

A stock analysis platform where the design problem was showing a lot of market data without overwhelming the reader. I designed the page and the charts so that price movement, RSI, MACD and moving averages can be read together, and added an index comparison view that sets a stock against its market benchmark.

Focus
Chart design, information hierarchy, comparison views
Built with
Python, Flask, Plotly, HTML, CSS, JavaScript

NIFTY Bank: Pre, During and Post COVID

Data storytelling and visual analysis

github.com/AlvinJoby/bank-nifty-covid

A visual study of how the NIFTY Bank Index behaved across three phases of the pandemic. I cleaned and segmented the data so each phase could be compared on the same terms, then shaped the charts to make the sharp decline and the recovery that followed easy to see.

Focus
Visual comparison, narrative structure, clarity of insight
Built with
Python, Pandas, Matplotlib, Jupyter Notebook
